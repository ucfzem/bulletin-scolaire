# Bulletin Scolaire Pro
Générateur de bulletins scolaires bilingue (FR/AR).

## Utilisation
Ouvrez `index.html` dans un navigateur. Remplissez les notes, la moyenne se calcule automatiquement. Exportez en PDF via le bouton d'impression.

## Fonctionnalités
- Bilingue français/arabe (RTL natif)
- Calcul automatique de la moyenne et mention
- Export PDF / impression
- Sauvegarde locale (localStorage)
- 100% mobile-first
